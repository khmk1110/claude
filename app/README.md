# 請求書・支払い管理ツール

代表宛に届く請求書PDFを秘書が取り込み、「支払済み/未払い」を一元管理するための
ローカル起動型の小さなWebアプリです。

## できること

- 請求書PDFをアップロードすると、金額・支払先・発行日・支払期限を自動抽出して登録
- 未払い一覧・支払済み一覧をダッシュボードで確認
- 支払期限が過ぎている請求書は赤色、7日以内のものは黄色でハイライト
- 抽出結果が間違っている/抽出できなかった場合は編集画面で修正可能
- 元のPDFはいつでも開いて確認できる

PDFのフォーマットは請求書ごとに異なるため、自動抽出はあくまで補助です。
登録後は一覧・編集画面で内容を確認してください。

## 起動方法(ダブルクリックでOK)

このフォルダの中にある、お使いのパソコンに合わせたファイルをダブルクリックするだけです。

- Windows: `start_windows.bat`
- Mac: `start_mac.command`

初回だけ「初回起動の準備をしています…」と表示され、少し時間がかかります
(裏側で必要な準備を自動で行っています)。2回目以降は数秒で起動します。

準備ができると自動でブラウザが開き、アプリの画面が表示されます。
黒い画面(ウィンドウ)が開いたままになりますが、これは正常な状態です。
**このウィンドウを閉じるとアプリが終了します。** 使い終わったら閉じてください。

もし「Pythonが見つかりません」という案内が出た場合は、表示された案内に沿って
Pythonを一度だけインストールしてから、もう一度ダブルクリックしてください。

### (参考)ターミナルから手動で起動したい場合

```bash
cd app
python3 -m venv .venv
source .venv/bin/activate   # Windowsは .venv\Scripts\activate
pip install -r requirements.txt
python3 app.py
```

## 使い方

1. 代表宛に届いた請求書PDFを、代表から転送してもらう or 共有フォルダ経由で受け取り、
   PCに保存する
2. ダッシュボードの「請求書PDFを取り込む」からファイルを選択してアップロード
   (複数ファイルまとめてアップロード可能)
3. 自動抽出された内容を確認し、間違っていれば一覧の「編集」から修正
4. 代表が実際に振り込んだら、その請求書の「支払済みにする」ボタンを押す
5. 支払期限が近い/過ぎている請求書は色付きで表示されるので、週次で未払い一覧を
   チェックして代表に共有する

## データの保存場所

- データベース: `app/data/payments.db` (SQLite、初回起動時に自動作成)
- アップロードしたPDF本体: `app/uploads/`

どちらもこのPC内にのみ保存され、外部には送信されません。
PCを買い替える場合などは `app` フォルダごとバックアップしてください。
