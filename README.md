# 給与・報酬管理システム

営業メンバー（個人事業主・正社員・インターン）の月次報酬を、
**「人間は事実を入力するだけ、計算はシステムが行う」** ためのWeb管理システムです。

## 起動方法

```bash
pip install -r requirements.txt
python run.py            # → ブラウザで http://127.0.0.1:5000 を開く
```

- データは `instance/payroll.sqlite3`（SQLite）に保存されます。別の場所にする場合は環境変数 `PAYROLL_DB` を指定。
- 動作確認用のデモデータ（引き継ぎ資料のメンバーと計算例）：`flask --app payroll seed-demo`（メンバー未登録のDBにのみ投入）
- テスト：`python -m pytest`

> ⚠ ログイン機能はありません。社内PC上（127.0.0.1）での利用を前提としています。サーバーに公開する場合は認証の追加が必要です。
> データのバックアップは `instance/payroll.sqlite3` をコピーしてください。

## 毎月の流れ

| 手順 | 画面 | 担当者がやること |
|---|---|---|
| 1 | ① 月次入力 | 対象月を選び【○年○月分を作成】を押す |
| 2 | ① 月次入力 A欄 | 出勤日数・当月獲得件数を入力して保存 |
| 3 | ① 月次入力 B欄 | 交通費・立替金・ガソリン代・その他報酬を「対象者・項目・対象月・金額・内容」で追加 |
| 4 | ① / ダッシュボード | 赤字のエラー・入力漏れがなくなるまで修正 |
| 5 | ② 支払一覧 | 全員の金額を確認し「確認」にチェック |
| 6 | ② 支払一覧 | 【○月を締める】→ 金額が固定される |
| 7 | ③ 個人別明細 | 氏名を選ぶ（または全員分表示）→【PDF出力（印刷）】で「PDFに保存」 |

前月獲得件数・単価・営業報酬・支払総額・合計はすべて自動計算です（画面上グレーの欄＝編集不可）。

## 計算ルール（システム固定）

個人事業主のみ自動計算します。

```
単価     = 単価表[ 当月出勤日数 ][ 前月獲得件数 ]     ← 前月件数は前月データから自動取得
営業報酬 = 当月獲得件数 × 単価                        ← 前月件数ではない
支払総額 = 営業報酬 + 交通費 + 立替金 + 立替・経費 + その他報酬 + 契約報酬 − ガソリン代
```

例：8月61件、9月出勤20日・9月50件 → 単価6,750円 → 営業報酬 50 × 6,750 = 337,500円

- 単価表は `payroll/rates.py` に固定（画面からは変更不可）。計算は `payroll/calc.py`。
- 交通費は「ワースリビング交通費 − 35,000円」を**差し引いた後の金額**を入力する。明細に35,000円控除は表示しない。
- 個人事業主に車手当は付かない（メンバー管理で個人事業主に自家用車フラグは設定できない）。
- ガソリン代は控除。「何月分か（対象月）」が必須で、複数月分は月ごとに1行ずつ登録する。
- 堀田さん：35,000円分は「立替・経費（会社負担）」として登録。メンバー管理の「立替・経費の目安」に35,000を設定すると、超過時に警告。サウナコンサル・プロパン等は「契約報酬」（内容必須）として登録。

## データを上書きしない仕組み

- 月ごとに別レコードで保存。9月を修正しても8月には影響しません。
- 区分は月次作成時点の値を保存（後で区分を変えても過去月は変わらない）。
- **締め**：締めた月は締め時点の計算結果を保存し、編集不可。前月の件数を後から直しても締め済みの月の金額は変わりません（差異がある場合は警告表示）。修正が必要なら理由を入力して締め解除。
- 入力変更・項目の追加削除・締め/解除はすべて「変更履歴」に記録されます。
