# claude

最初のリポジトリ

## タスク管理システム

タスクの漏れを防ぐための、シンプルなローカルWebアプリです。Flask + SQLite で動作し、期限切れ/期限間近のタスクを一覧上で強調表示します。

### セットアップ

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 起動

```bash
python app.py
```

ブラウザで http://127.0.0.1:5000 を開きます。データは `tasks.db`(SQLite、初回起動時に自動作成)に保存されます。

### 機能

- タスクの追加・編集・削除
- 状態(未着手・進行中・完了)の管理
- 優先度(高・中・低)とカテゴリでの分類
- 期限の設定、および期限切れ・期限間近(2日以内)のハイライト表示
- 状態・カテゴリでの絞り込み、期限順/優先度順/作成日順での並び替え
